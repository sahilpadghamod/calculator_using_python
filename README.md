# calculator_using_python
Command-line calculator supporting basic operations. 

This Calculator.py file contains the code for a command-line basic calculator. 
1) This calculator takes 2 inputs and performs operations like +, -, *, /
2) Just like a traditional calculator. The last result of the calculation is taken as the first input for the next operation.
